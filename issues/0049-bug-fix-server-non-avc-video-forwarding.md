# サーバーサンプルで非 AVC 映像を再生側に転送する

- Created: 2026-11-23
- Completed: {YYYY-MM-DD}
- Branch: feature/fix-server-non-avc-video-forwarding
- Polished: {YYYY-MM-DD}

## 目的

サーバーサンプルで、配信開始から非 AVC の映像を使うストリームを、AVC のデコーダー設定なしで再生できるようにする。

## 現状

サーバーサンプルの `handle_video_received` は、キーフレームかつ AVC の `SequenceHeader` を受け取った場合だけ、再生側に送る設定データを保持する。一方、再生側が設定データをまだ受け取っていないと、入力のコーデックを問わずその設定データを待つ。

新しいストリームで VP6 などの非 AVC のキーフレームと後続の映像を受信しても、AVC の設定データが現れないため、再生側への映像の転送が始まらない。

## 設計方針

AVC 設定データの送信を、AVC 映像を転送する場合だけの条件にする。AVC の設定データを映像より先に送る処理と、再生側へキーフレームから映像を送る処理は維持する。ライブラリの FLV や RTMP の公開 API は変更しない。

## 完了条件

- 新しい非 AVC ストリームでは、AVC 設定データなしでキーフレームから映像が再生側に転送される。
- AVC ストリームでは、再生に必要な AVC 設定データが映像データより先に送られる従来の挙動を維持する。
- 両経路で、再生側が実際に受け取るフレームとその順序を検証する。
